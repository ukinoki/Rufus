Le programme démarre en vérifiant que la version de MacOS est Monterey ou une version postérieure à Monterey
Je veux simplifier l'interface. Elle se limite à une boîte de dialogue demandant un login et un mot de passe à l'utilisateur.
                . le login doit avoir une longueur comprise entre 5 et 15 caractères, uniquement des chiffres ou des lettres
                . le mdp doit avoir une longueur comprise entre 5 et 12 caractères, uniquement des chiffres ou des lettres
Puis, il vérifie que MySQL est déjà installé

Si MySQL est déjà installé, il vérifie d'abord que cette version est la version 8.4.3
           Si c'est une version antérieure, il propose de la faire évoluer vers la version 8.4.3. En cas de refus, le programme se ferme.
           En cas d'acceptation, une QProgressBar s'affiche pendant l'installation
           Le programme essaie de se connecter à la base MySQL avec le login et le mdp fournis.
           Si la connexion est impossible, le programme demande un autre login et un autre mdp et réessaie en boucle
           Le programme vérifie que l'utilisateur a tous les privilèges, y compris GRANT OPTION
           Si ce n'est pas le cas, le programme demande un autre login et un autre mdp et réessaie en boucle

Si MySQL n'est pas installé, le programme l'installe, une QProgressBar s'affiche pendant l'installation et un utilisateur est créé avec le login et mdp fourni, avec tous les privilèges, y compris GRANT OPTION

Si le dossier /Users/Shared existe, le programme vérifie s'il est partagé sur le réseau. Si ce n'est pas le cas, le dossier /Users/Shared est créé s'il n'existe pas et est partagé sur le réseau
Le programme vérifie que la variable secure_file_priv pointe sur /Users/Shared et si ce n'est pas le cas, il modifie cette variable pour la faire pointer sur /Users/Shared
Le programme vérifie que la variable sql_mode est égale STRICT_TRANS_TABLES,NO_ENGINE_SUBSTITUTION et si ce n'est pas le cas la modifie pour qu'elle soit égale à STRICT_TRANS_TABLES,NO_ENGINE_SUBSTITUTION

Si tous les critères sont réunis
1. base MySQL 8.4.3
2. utilisateur avec login conforme, mdp conforme et tous les privilèges y compris GRANT OPTION
3. secure_file_priv et sql_mode conformes
4. /Users/Shared existant et partagé sur le réseau
Le programme se ferme après un message disant que tout s'est bien déroulé

Si tous les critères ne sont pas réunis, le programme affiche les critères qui posent problème et la raison des problèmes, avant de se fermer.
